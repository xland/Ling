# Ling

一个使用现代 C++ 开发的GUI框架，仅为Windows桌面应用服务。

# 特性

- 基于 [windows.ui.composition](https://learn.microsoft.com/en-us/uwp/api/windows.ui.composition) 完成渲染工作。
- 使用 [Yoga](https://github.com/react/yoga) 作为布局引擎
- Release编译产物 < 1M
- 可以编译为单文件exe
- 目前应用于 [ScreenCapture](https://github.com/xland/ScreenCapture) 项目
